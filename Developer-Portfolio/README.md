# 🚀 Full Stack Developer Portfolio Website

A premium, interactive developer portfolio showcasing skills, projects, experience, and an interactive Guestbook comments system.

🔗 **Live Demo:** https://developer-portfolio-v5.vercel.app/

## 🛠️ Tech Stack & Features
- **Frontend:** React.js (Vite), Tailwind CSS, Framer Motion, AOS (Animate on Scroll), Lucide Icons
- **Backend/Database:** Firebase (real-time comments guestbook, database integrations)
- **Interactive Laptop/Desk Scene:** CSS-animated desk setup, interactive typewriter title, floating tech cards
- **Guestbook:** Interactive comment board supporting optional profile photos, emojis, and real-time replies
- **Responsive & Premium Design:** Sleek dark-mode aesthetic with custom animations and fluid responsive layouts
